Sewer-P v1.0.23 — самостоятельный EXE и Hello Tanya

Для запуска без лаунчера скачайте Sewer-P-Windows-x64-v1.0.23.zip, распакуйте архив и откройте Sewer.exe. Python отдельно устанавливать не нужно.

- Один Sewer.exe для Windows 10/11 x64, без консольного окна, с иконкой ёжика.
- Python, Qt, библиотеки графика и ресурсы оформления включены в EXE.
- Настройки, Logs и Temp сохраняются рядом с EXE; для защищённой папки используется %LOCALAPPDATA%\Sewer-P.
- Существующий config.json можно перенести рядом с EXE до первого запуска. EXE его не заменяет встроенными значениями.
- Тема Hello Kitty переименована в Hello Tanya в главном окне, настройках и предпросмотре. Прежний сохранённый выбор совместим.
- Упакованное приложение корректно запускает внешний Programmer и сторонние программы с их собственными путями поиска DLL.
- Функции Rigol и маркеры сохранены из v1.0.22.

Драйверы VISA x64 и USB-COM, внешний Programmer и прошивка используются установленные на компьютере. Они не входят в EXE.

Проверка Windows-сборки включает запуск EXE дважды из папки с пробелами и кириллицей, без Python в PATH, открытие главного окна, настроек и Rigol, наличие встроенных изображений и сохранение настроек после перезапуска. Работа с физическими приборами требует проверки на стенде.

Sewer-Windows.zip — совместимый архив исходников для прежнего лаунчера. Самостоятельная EXE-версия находится в отдельном архиве Sewer-P-Windows-x64-v1.0.23.zip. Контрольные суммы — SHA256SUMS.txt.
