Sewer-P v1.0.28 — ручное питание и скриншоты Rigol

• «Включить» в правом верхнем углу блока «Источник питания»: ручная подача питания с проверкой лимитов и тока, как Alt+Z. «Стоп» / Esc отключают выход.
• «Скриншот» в блоке Rigol: PNG экрана анализатора по Ethernet через Web Control. Ctrl+Alt+S работает в активных окнах Sewer-P. Захват идёт в фоне и не выполняет клик Rmt.
• Ёжик → Rigol: папка, имя и выбор нумерации снимков. Существующие PNG не перезаписываются.

Сборка на Windows x64 с Python 3.12, из папки Sewer_Python_DEV2_FULL:
    python -m venv .venv
    .venv\Scripts\python.exe -m pip install -r requirements-build.txt
    .venv\Scripts\python.exe build_windows.py

Готовый файл: dist\Sewer.exe. Рядом с ним положите свои config.json и rigol_presets.json.
