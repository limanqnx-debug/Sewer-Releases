Sewer-P v1.0.22 — маркеры Rigol на спектре

Основа — v1.0.21, отображение всей полосы которой подтверждено на приборе.

- Новая вкладка «Маркеры»: M1–M8, Normal / Delta / Fixed / Off, выбор Trace и опорного маркера.
- Цветные обозначения маркеров поверх спектра; таблица частоты/времени и уровня всех включённых маркеров под графиком. На графике показываются маркеры выбранной Trace.
- Частота вводится в MHz, при Span = 0 — время в ms. Единицы находятся за полем; ввод поддерживает точку и запятую, Enter, Set и колесо мыши.
- Peak Search, Next Peak, поиск пика слева/справа, Minimum и непрерывный Peak Search.
- Marker → Center, Marker → Ref Level, Δ → Span и отключение всех маркеров.
- Команды и опрос маркеров выполняются в фоне, через общую блокировку VISA. После команды считываются реальные состояния и значения прибора. Автоопрос маркеров — раз в 1,5 с при включённом Live; фактический интервал зависит от связи и количества включённых маркеров.
- Для Trace добавлены Display и Update с обратным чтением. Панель параметров прокручивается, поэтому нижние элементы доступны в невысоком окне.
- Состояние маркеров включено в диагностический ZIP.

Откройте Rigol → Управление → Маркеры. Выберите M1, Normal и нужную Trace → «Применить режим / Trace» → Peak Search. Для Delta сначала включите другой опорный маркер Normal или Fixed.

Флажок «Маркеры» над графиком управляет отображением и автоопросом в Sewer-P. Чтобы выключить маркеры на самом приборе, используйте режим Off или «Выключить все маркеры». При выключенном Live кнопка «Прочитать маркеры» запрашивает один набор показаний.

В GPSA поддерживаются частотная и временная развёртки, в RTSA — Normal/Density. Delta рисуется по абсолютным координатам, восстановленным из нормального/фиксированного опорного маркера, для логарифмических единиц уровня. Неоднозначные координаты, специальные функции маркера, обратное время/период и недостоверные ответы не заменяются придуманными точками на графике.

Чтение полной ASCII-трассы и управление соединением из v1.0.21 сохранены. Главное окно, журнал и производственный цикл не менялись.

Проверены 38 тестов Qt/VISA-имитатора, включая полный спектр 801/10001 точек, Delta, время при Span = 0, обратное чтение, обновление оси при остановленном Live и остановку опроса при закрытии окна. Интерфейс проверен в Qt. Новые команды маркеров ещё нужно проверить на физическом RSA5065N.
