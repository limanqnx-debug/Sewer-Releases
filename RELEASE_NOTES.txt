Sewer-P v1.0.27 — пресеты Rigol

В блоке Rigol появился выбор пресета по названию и кнопка «Применить».
Редактор таблицы доступен только через ёж → Настройки → Пресеты Rigol.
Добавление, копирование, удаление, переименование (двойной щелчок по названию), чтение настроек с прибора и сохранение.

35 столбцов: название, режим GPSA/RTSA, Trace, Center/Span/Ref/Att/Offset, Sweep Points/Time, Trace Type/Det, RBW/VBW; частоты и функции M1–M3, Band Function, Band Span, режимы маркеров, Auto для Band/RBW/VBW/Sweep Time.
Пусто = не менять. МГц / кГц / мс; поддерживается десятичная запятая. Начальные строки «Пресет 1–3» пустые.
Func OFF/NOIS/BPOW/BDEN и Band Function BPOW/BDEN задают одну функцию прибора; при конфликте пресет отклоняется до команд. Частота включает Normal, если режим явно не указан; POS/FIX/OFF можно задать отдельным столбцом. Чтение Delta требует сначала выбрать Normal/Fixed. Частотные маркеры не применяются в Zero Span.

Применение и чтение выполняются в фоне с общей блокировкой VISA и паузой Live/маркеров. После применения считываются реальные значения и ошибки прибора. Скорректированные прибором числовые значения отмечаются в окне и журнале. Несовместимые с RTSA Sweep/VBW не отправляются: выберите GPSA либо оставьте ячейки пустыми. При ошибке применения часть настроек уже могла измениться; отката нет.

Таблица сохраняется в rigol_presets.json рядом с config.json (в защищённой папке — в каталоге данных Sewer-P). Сохраняется резервная копия rigol_presets.backup.json. При обновлении переносите оба файла: config.json и rigol_presets.json. В архиве обновления таблицы пользователя нет.
Главное окно увеличено до 1040×740 для размещения строки пресетов.

Автоматические проверки: сохранение/резервная копия/неизвестные поля, ввод с запятой, валидация до команд, чтение фактических значений, конфликты Auto, RTSA, маркеры и нулевая полоса, Qt-интерфейс и фоновая задача. Windows-сборка проверяет редактор и сохранение пресетов при двух запусках EXE без Python в PATH. Физический RSA5065N требуется проверить отдельно.
