Sewer-P v1.0.19 — чтение спектра по рабочей PowerShell-реализации

Сравнён реальный Modules/Rigol.psm1 из DEV5 TRACE LIVE2 — 300 ms.

- Для USB и Ethernet INSTR Trace читается до конца сообщения VISA, как в PowerShell viRead; перевод строки внутри ASCII-блока не обрывает массив. Для TCPIP SOCKET сохранён перевод строки.
- Удалён обязательный запрос подтверждения формата. Чтение Trace использует установку ASCII и запрос данных, как рабочая версия.
- Служебные запросы шкалы, типа, Display и Update исключены из каждого кадра. Они читаются при открытии/изменении управления и не являются условием отображения спектра.
- Автомасштаб Y включён по умолчанию, как в PowerShell.
- Расхождение количества точек больше не скрывает весь график: после повторной проверки Sweep Points данные при необходимости показываются по номерам точек с пояснением.
- Проверка целостности блока с заголовком, ошибок VISA и числовых значений сохранена. Ошибочные точки не отбрасываются молча и не заменяются выдуманными значениями.

Главное окно и журнал сохранены. Управление приборами, ввод с клавиатуры, единицы за полями и сохранение диагностики остаются доступными. PowerShell в рабочую логику не возвращается.

Проверены 20 тестов, включая многострочный ответ с узким пиком, 10001 точку, отсутствие служебных ответов, несовпадение Sweep Points, USB/VXI-11, восстановление терминатора после ошибки и интерфейс Qt. Это проверки с имитатором; причину на физическом Rigol необходимо подтвердить.

После обновления откройте Rigol → Управление, выберите тот же GPSA и Trace 1, которые работали в PowerShell. Live и Автомасштаб Y включены по умолчанию. Если изображения всё ещё нет, сохраните диагностику и пришлите ZIP со снимком экрана Rigol.
