Sewer-P v1.0.16 — база v1.0.14, спектр только в управлении Rigol

Восстановлено главное окно v1.0.14: нижний блок снова является журналом событий. Добавленная в v1.0.15 вкладка спектра в главном окне убрана.

Исправлен Live Spectrum в окне «Rigol — управление». Live включён по умолчанию и начинает чтение при открытии окна. При закрытии, в том числе по Esc, опрос спектра прекращается. Повторное открытие запускает новый сеанс отображения.

Сохранены Trace 1–6 и интервал 300 ms из настроек. Добавлена кнопка «Обновить» для одного кадра, включая паузу Live. Ошибки чтения и отсутствие данных показываются под графиком. Опрос выполняется в фоне без накопления запросов.

Настройки, темы и производственный контроллер взяты из v1.0.14. Номер v1.0.16 позволяет установить эту сборку через лаунчер поверх v1.0.15.

Проверены Qt и имитатор VISA: автоматический запуск, 801/10001 точка, таймауты, восстановление, пауза, смена трассы, закрытие по Esc и повторное открытие. Проверка с реальным RSA5065N на Windows остаётся необходимой.
