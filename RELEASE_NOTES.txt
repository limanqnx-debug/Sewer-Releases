Sewer-P v1.0.21 — исправление обрыва Trace на 4096 байтах

Диагностика v1.0.20 подтвердила: GPSA, Sweep Points = 801, прочитано 4096 байт без конца строки, разобрана только 241 точка.

- ASCII-ответ без заголовка больше не считается полным после первого фрагмента. Программа дочитывает текущий ответ до завершения массива.
- В GPSA актуальное Sweep Points запрашивается до Trace; между частями ответа новые команды прибору не отправляются.
- Размер запроса VISA ограничен 4096 байтами, готовая трасса собирается из всех полученных частей.
- Неполный массив больше не отображается как спектр с осью «Номер точки». При обрыве показывается ошибка; сбившаяся сессия закрывается, Live приостанавливается.
- В диагностический ZIP добавлены размеры частей, статусы VISA и общее число байт для каждого ответа Trace.

Сохранены LF-завершение, восстановление соединения из v1.0.20, главное окно на основе v1.0.14, журнал, оформление и производственный цикл.

Проверены 32 теста Qt/VISA-имитатора: обрыв 4096 байт / 241 точка, дочитывание до 801 и 10001 точки, пик за границей первой части, обрыв в числе или заголовке, отсутствие продолжения и чистый следующий запрос. Отдельная проверка использует первый блок из реального архива и искусственное продолжение. Работа исправления на физическом RSA5065N ещё требует подтверждения.

Закройте Sewer-P, обновитесь через лаунчер и откройте Rigol → Управление. При Sweep Points = 801 под графиком должно быть 801 точка и частотная ось. Если продолжение не приходит, сохраните новый диагностический ZIP: он покажет результат каждой операции чтения.
