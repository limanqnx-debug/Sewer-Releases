Sewer-P v1.0.26 — Span, горячие клавиши и освобождение Rigol

В RTSA добавлены Span 250 и 750 кГц. Доступны шесть кнопок: 250 / 500 / 750 кГц / 1 / 1,5 / 2 МГц, с чтением фактической полосы и обновлением графика.

Alt+C — переключение GPSA / RTSA вместо Alt+Пробел.
Alt+Z — включение источника без прошивки, с проверкой реальных ограничений напряжения/тока и защитой по току. Отключение — «Стоп» / Esc в главном окне.
Alt+Ctrl+C — освобождение / подключение Rigol. В главном блоке также есть кнопка «Освободить» / «Подключить». Сочетания работают в активных окнах Sewer-P.

Освобождение останавливает Live, маркеры и фоновый опрос, закрывает VISA. По Ethernet используется способ рабочего виджета: нажатие Rmt через Web Control в скрытом окне установленного Яндекс Браузера, Edge или Chrome. На Rigol должен быть включён Display → Web Control. По USB используется VISA Go To Local. При ошибке опрос остаётся остановленным, причина выводится в журнал. Повторное подключение восстанавливает опрос.

Исправление обновления напряжения и тока после Repeat сохранено. Автоматические проверки включают Qt/VISA-имитаторы и запуск готового Windows EXE с проверкой браузерного компонента на локальном макете Web Control. Физическую панель Rigol нужно проверить на приборе.

Sewer-Windows.zip — обновление через лаунчер, теперь с готовым Sewer.exe и необходимыми Python-компонентами. Настройки сохраняются механизмом лаунчера.
Sewer-P-Windows-x64-v1.0.26.zip — самостоятельный EXE. При обновлении замените Sewer.exe, сохранив свой config.json.
Sewer-P-Source-v1.0.26.zip — исходники для запуска через Python и повторной сборки.
